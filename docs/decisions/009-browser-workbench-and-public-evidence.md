# ADR 009：浏览器工作台与公开证据摘要

- 日期：2026-10-07
- 状态：采用
- 对应阶段：P09

## 问题

P08 已提供可恢复的 HTTP 工作流。浏览器需要把运行、业务进度、人工待办与已提交动作区分开，并正确处理刷新、请求回执丢失和另一位操作员修改方案。

## 决定

1. 使用原生 HTML/CSS/JavaScript，由同一 FastAPI 服务提供 `/` 和 `/assets`。三个资源随 wheel 分发，无前端构建或外部字体依赖。根页面设置 CSP，只允许同源脚本、样式与请求，禁用嵌入和对象资源。
2. 浏览器只使用 P08 HTTP 接口。身份选择使用已有公开演示令牌；`can_respond` 来自服务器，权限、版本、规则和写入仍由服务器检查。
3. 扩展公开 DTO：动作政策 ID/版本、证据来源和有限摘要、缺口、审核结果/问题、输入/方案版本、活动耗时与修复计数。证据摘要按可信来源类型构造，禁止返回原始 facts、图状态、提示词、模型消息或操作账本 key。电话/邮箱/令牌文本沿用演示脱敏。
4. 新字段给默认值，P08 已保存的公开结果仍能读取。旧结果缺少新增摘要时显示空状态，不为补齐页面资料自动重跑工作流。本轮无需数据库迁移。最近活动时间取实际客户消息、任务登记和动作提交时间，不伪造通用 updated_at。
5. 每次 POST 在发送前生成并保存 UUID 请求键。响应不确定时保留原路径、正文、身份和键；重试及刷新后重试复用它们。确认成功后释放该提交的键，使下一次明确操作能产生新请求。按钮同步进入 busy 状态；数据库的请求幂等和动作账本继续承担最终保护。
6. 单页轮询串行执行，身份/工单切换递增 generation，过期响应不得写回界面。事件页完整收到后才推进 after_seq；断线保留游标，序号去重。刷新后从服务器重读待办与历史事件，不只信任浏览器缓存。
7. 表单按待办版本渲染，普通轮询不覆盖填写内容。待办变化或 409 时废弃旧表单，展示当前版本，勾选确认恢复为未选。审批包含完整 proposal/action hash；修改金额仍是 revise → 重新审核 → 再确认。
8. 金额以整数分处理，输入元采用字符串拆分，拒绝超过两位小数和 JavaScript 安全整数范围。无法精确显示的金额禁止页面确认。时间用 Intl 显示为 Asia/Shanghai。
9. 业务状态和 run 状态独立显示；退货登记为“待客户寄回”，物流调查登记为“处理中”。已提交回执与审批前回复草稿分别展示，草稿明确标注尚未发送。
10. Playwright 测试使用真实 Chromium、临时 Uvicorn、LangGraph 和 SQLite；只允许浏览器请求该测试的 loopback 服务。默认离线 pytest 保持禁止网络，E2E 独立启动。CI 单独安装 Chromium，并保存截图、HTTP 观测和 replay trace。

## 取舍

保留单机 POSIX、单 HTTP 服务进程、脚本模型和模拟动作范围。浏览器 sessionStorage 为同一标签页保留选择和未确认请求，清空存储后不保证恢复未确认提交的请求键；服务器仍阻止活跃工单冲突和重复业务动作。当前搜索/筛选作用于列表当前页，事件默认显示最近 60 条，可展开全部。演示凭证与文本正则不替代生产认证或数据治理。

## 证据

- `tests/test_web_contracts.py`：同源资源、CSP、接口身份边界、证据 allowlist、脱敏和 P08 结果兼容。
- `tests/test_api.py`：政策/证据公开投影、版本、审核与统计字段，以及既有 HTTP 幂等/范围/容量约束。
- `tests/test_workbench_e2e.py`：三类业务闭环；刷新补充；双击；启动/审批回执丢失；事件重连；另一位操作员 revise 后真实 409；页面金额修订；真实执行器中断后恢复/取消；身份范围、恶意文本、搜索空态、窄窗口表单和时间线。
- `docs/graphs/p09-demo-browser.json`：三条实际浏览器路径的 HTTP 记录和结束画面观测。教学单次计时不代表性能评估。
- `docs/screenshots/p09-desktop.png` 与 `p09-narrow.png`：桌面和窄窗口人工待办截图。
