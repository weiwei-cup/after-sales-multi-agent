# 路线图

当前发布已覆盖完整单机演示链路：工单 → 调查 → 证据与规则 → 审核 → 人工输入 → 模拟动作 → 回执与恢复。交付范围、测试与评估分别见 [架构](technical-design.md) 和 [质量报告](quality.md)。

## 已交付

- 三类售后业务、版本化模拟资料与政策规则。
- 单 Agent、串行/审核/持久多 Agent、并行调查与受校验的结果合并。
- 客户补资料、方案修订、版本化确认与有限返工。
- SQLite 检查点、持久输入、请求接纳、动作账本、预算与取消。
- FastAPI、中文工作台、公开证据摘要与游标轮询。
- 真实恢复/并发/HTTP/浏览器测试及独立单/多 Agent 对照。
- 统一演示入口、文档中心、发布版本与可安装 wheel。

## 后续方向

| 优先级 | 方向 | 验收方式 |
| --- | --- | --- |
| 高 | C11/C14 停止分类、C17 证据保留、H10 已退款分支与回复 | 新增针对业务预期的回归，用新留出集评估；保留原报告 |
| 高 | 真人引用与语义复核 | 标注 reviewer、样本选择、依据与分歧，不用模型抽查替代真人 |
| 高 | 真实模型适配器 | 工具/结构化输出协议、超时重试、实际 usage；至少三次采样，记录失败、波动与价格快照 |
| 中 | 真实身份与访问控制 | 去除公开演示令牌，验证跨客户与角色权限、凭据与审计边界 |
| 中 | 外部售后、支付与消息通道 | 接口幂等、持久投递、失败重试/对账；沙箱端到端验证 |
| 后续 | 分布式存储与执行 | 明确数据库/队列、租约接管、迁移与多实例失败窗口，再验证并发正确性 |

路线图不代表这些能力已经实现，也不承诺真实模型的质量/成本收益。原逐阶段任务与历史验收保存于 [实施计划归档](history/implementation-plan.md)。
